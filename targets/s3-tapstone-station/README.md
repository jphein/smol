# s3-tapstone-station — the Tapstone shrine station on the ES3C28P

A real shrine at a Tapstone table (tapstone#132 item c). `--features tapstone-station` is
[`s3-tapstone-gw`](../s3-tapstone-gw/README.md) plus the seat: `tapstone_proto::shrine::Shrine`,
the state machine tapstone's arena tests run as `DeskShrine`, over the vendored `rules-v0.2.0`
crates (`rust/tapstone-*`, `rust/shrine-render`, `rust/tapstone-decks`). Until a card reader is
wired, the seat chooses its taps with `shrine::Autoplay`. Code: `rust/clock/src/tapstone_station.rs`
(the seat and radio) and `tapstone_screen.rs` (0032's screens).

**Status: ✅ verified on katana's table, 2026-09-27.** Boards id61 and id62, with the arena on
katana. Evidence below.

## One image, two roles

- **The arena's own board** (seat A plus the arena's radio). The arena's `@TS1 TX` lines for this
  seat's node, and its broadcasts, are delivered locally. The seat's frames go up the USB as
  `@TS1 RX` lines from its node. Build it with `TAPSTONE_STATION_NODE` (161 at the table), because
  the arena drops every frame from its own gateway's node as an echo.
- **A remote board** (seat B). Frames arrive off ESP-NOW from the arena's gateway and go back to
  it through `send_to`, carrying the #190 trailer.

The station learns which case it is in from the arena's frames: a lobby beacon that names no
seat, `B`, commits, `R`, rejects. It then replies the way they came. A `BadTag` frame never
reaches the seat. After a match it holds the result for 10 s before claiming again.

## Build

```sh
SMOL_NODE_ID=61 TAPSTONE_STATION_NODE=161 TAPSTONE_DECK=ember-neutral TAPSTONE_INDEX=0 targets/s3-tapstone-station/build.sh
SMOL_NODE_ID=62 TAPSTONE_DECK=tide-neutral TAPSTONE_INDEX=1 targets/s3-tapstone-station/build.sh
```

The recipe comes from `[hand_build.s3-tapstone-station]` (tier `tapstone-station`):
`esp32s3,hw,tapstone-station,espnow`. It has no `cast`, because the station draws the colour panel
itself, and no `io`, because P3 belongs to a reader. The build knobs are listed in `build.sh`'s
header. Build with the same `secrets.rs` as the gateway the station talks through: a station
with another group key sees the arena's frames as `BadTag`. The deck tables are generated by
`rust/clock/build.rs` from `rust/tapstone-decks/decks/*.toml`, and a deck file it can't parse
fails the build.

On the C3 the same tier is CI's lint arm: a headless seat with no screens. fw-gate's
`hand builds` job compiles this folder's S3 recipe with CI's throwaway key.

## Screens (tapstone decision 0032)

The screens are Dark (arena not heard), Idle, the in-match station (paperdoll, wells, locator,
voice band) and Result. `shrine-render` draws them into a static 320×24 band, and each band goes
out as one windowed write. Measured paints: station 75 ms mean and 84 ms max, idle 61 ms, result
73 ms, dark 54 ms. The pixels have not yet been checked by eye.
